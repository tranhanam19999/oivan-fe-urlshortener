# UrlShortener UI

This document is intended for setup and runs the code at locally

## Requirements
- node version v22.12.0
- Angular CLI installed (https://angular.dev/installation)
- A steady mindset to work with CSS

## Steps to setup to run the code at locally

Run these in the terminal where at the root directory of the project

### **Step 1:** `npm install`

For building the docker image for the database and init swagger

### **Step 2:** `npm start`

To start the UI at locally
